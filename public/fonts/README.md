| File | Family | Style | Upstream |
| --- | --- | --- | --- |
| Amiri-Regular.ttf, Amiri-Bold.ttf | Amiri | Naskh | https://github.com/aliftype/amiri |
| ArefRuqaa-Regular.ttf, ArefRuqaa-Bold.ttf | Aref Ruqaa | Ruqʿa | https://github.com/alif-type/aref-ruqaa |
| NotoNastaliqUrdu.ttf | Noto Nastaliq Urdu | Nastaʿlīq | https://github.com/notofonts/nastaliq |
| ScheherazadeNew-Regular.ttf | Scheherazade New | Naskh | https://software.sil.org/scheherazade/ |
| ReemKufi.ttf | Reem Kufi | Kufi | https://github.com/aliftype/reem-kufi |
| Katibeh-Regular.ttf | Katibeh | Display | https://github.com/google/fonts/tree/main/ofl/katibeh |
| Rakkas-Regular.ttf | Rakkas | Display | https://github.com/zeynepakay/Rakkas |

Exported artwork contains glyph outlines from these fonts; the OFL allows this for documents and images.
